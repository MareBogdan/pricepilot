"Are these the same purchasable unit, such that a price-comparison engine should compare their prices?"

Answers

  • M match — same purchasable unit
  • N no match — different unit or product
  • S skip / uncertain — a real answer, not a failure
  • U undo last decision
  • F flag (add to any answer — e.g. reformulation, worth a second look)

N — always

  1. Different net weight/volume
  2. Multipack vs single unit
  3. Bonus pack vs plain pack
  4. Different flavour/protein
  5. Different breed size, same weight
  6. Different life stage (incl. Adult vs Adult 7+/Senior)

M

  1. Same product, different brand string (distributor code vs manufacturer) — judge from title/packaging, not the brand field alone

S

  1. One side states no weight at all
  2. (reformulation → M, flagged, not S)
  3. Uncertain for >~15 seconds
